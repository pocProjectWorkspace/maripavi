# Happy Birthday Pavi — Enhanced Edition

Static Vercel-ready website with 18 photos (8 original + 10 new), swipeable carousel, responsive gallery, full-screen lightbox and birthday surprise.

## Deploy

Upload the **contents of this folder** to the root of your GitHub repository, or set Vercel Root Directory to the folder containing `index.html`. Framework: Other; no build command; output directory default.

If keeping the old GitHub layout, replace the files inside `Pavi_Birthday_Vercel_Website/` with the contents of this ZIP. Set Vercel Root Directory to `Pavi_Birthday_Vercel_Website`.

The site uses no backend, Node.js or API keys.
